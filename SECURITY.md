# Security policy

This repository has not yet been published and no public vulnerability-reporting address has been
designated. Until then, report concerns privately to the repository owner through the channel by
which you received the project.

Do not include credentials, authentication directories, private data, or raw transcripts in an
issue or pull request. See [docs/SECURITY.md](docs/SECURITY.md) for operational guidance and
[PRIVATE_DATA.md](PRIVATE_DATA.md) for incident handling.
