# Public and private data

The repository includes only 15 newly authored synthetic demo entries and two labeled mock
fixtures. The historical 4,812-entry list, spreadsheets, complete outputs, source-adjacent examples,
and transcripts remain private because authorization and redistribution boundaries are not
established for public release.

Public contributions need documented origin, ownership/rights basis, intended use, and privacy
review. Never assume that model-generated or transformed text is automatically unrestricted.
Production inputs and outputs belong in ignored local directories.

The repository-root `PUBLIC_DATA_POLICY.md`, `PRIVATE_DATA.md`, `LICENSE`, and `DATA_LICENSE` are
the controlling publication documents.
