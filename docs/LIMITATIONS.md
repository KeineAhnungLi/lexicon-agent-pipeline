# Limitations

- The included prompt/schema is a German–Chinese A1/A2 profile, not a finished universal ontology.
- Codex CLI is the only formal model provider implemented; API provider names are extension points.
- MockProvider demonstrates deterministic control flow only.
- No public gold corpus, semantic benchmark, Judge experiment, human agreement result, or accuracy
  number is included.
- CSV import, adjudication UI, stratified split tooling, model-Judge execution, and human-time
  tracking remain planned.
- Automated public audit cannot prove copyright ownership, catch every secret, or replace legal and
  privacy review.
- Containerized Codex authentication is not supplied.
- Newly added datasets still require independent provenance, privacy, and rights review even though
  the included original synthetic fixtures are dedicated under CC0-1.0.
