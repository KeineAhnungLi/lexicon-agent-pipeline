# Public case study

The public demo proves the orchestration path without publishing production material. Fifteen newly
authored synthetic headwords exercise capitalization, polysemy, separable/reflexive verbs, optional
spelling, abbreviation, phrase, and collocation pairing.

Mock generation and review both emit valid 29-field records. Simple mode can merge generation;
full mode merges review. In either case the same deterministic step inserts `meaning_merged`, and
the 30-field final artifact is revalidated. This is an operational demonstration, not an accuracy
benchmark or human verification claim.
