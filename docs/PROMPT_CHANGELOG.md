# Prompt changelog

## 1.0.0

- Made “one entry, one linguistic judgment” a non-negotiable method.
- Explicitly prohibited suffix-based meanings, translation lookup tables, and semantic templates.
- Split generation from an independent review prompt.
- Defined exact 30-field order, missing marker, controlled values, index and input-identity rules.
- Added focused handling for capitalization, reflexive/separable verbs, bracket notation, fixed
  expressions, abbreviations, and polysemy using newly authored examples.
- Made mechanical validation’s limitations explicit.
- Added a fixed provenance phrase and human-verification notice.
- Replaced source-adjacent examples with public synthetic examples.
